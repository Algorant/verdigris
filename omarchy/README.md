# Verdigris for Omarchy (moved)

The Omarchy theme now lives in its own repository: **[Algorant/omarchy-verdigris-theme](https://github.com/Algorant/omarchy-verdigris-theme)**. It was carved out of this folder with its history kept.

```sh
omarchy theme install https://github.com/Algorant/omarchy-verdigris-theme
```

It installs as `verdigris`. Its README covers the wallpapers, the palette mapping, OLED panels, and what gets themed beyond Omarchy's default colour inheritance.
