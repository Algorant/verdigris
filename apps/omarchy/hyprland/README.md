# hyprland

- Window borders, coloured by the Omarchy theme
- [hyprland](https://github.com/hyprwm/Hyprland), configured by [omarchy](https://github.com/omacom/omarchy)

## files

- [`verdigris.lua`](verdigris.lua): documents the border colours; nothing to paste in

## notes

The borders come from the Omarchy theme. Omarchy generates them from `colors.toml` when the theme is set, so there is no manual step and `verdigris.lua` is not installed anywhere. It exists so the values can be read in one place.
