# verdigris for foot

GUI terminal, Wayland native. The second terminal I keep around.

## install

Copy `verdigris.ini` into `~/.config/foot/` as `verdigris.ini`, then start foot with `-c ~/.config/foot/verdigris.ini`.

## notes

The palette sits under `[colors-dark]` so foot's own light mode is untouched.
