# verdigris for quickshell

GUI widgets on the desktop shell. The calendar, notification and monitor panels.

## install

Each widget reads the shell colours generated from the omarchy theme, so installing [the omarchy theme](https://github.com/Algorant/omarchy-verdigris-theme) colours them. There is no separate file to copy.
