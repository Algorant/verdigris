# verdigris for chromium

GUI browser. Chromium when I need a Chromium-family window.

## install

Copy `verdigris.theme` into your Chromium profile's theme path, or paste the three numbers into the theme field your setup expects.

## notes

The file is a single RGB triplet, which is what Chromium's theme hook reads. Zen is my default browser and stays unthemed.

Screenshot deferred with the other windowed apps.
