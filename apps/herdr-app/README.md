# verdigris for herdr app

GUI desktop app. My terminal and agent window.

## install

Copy `verdigris.json` into `~/.config/herdr-app/themes/`, then pick verdigris in the theme menu.

## notes

Dark only. Used on my desktop and laptop; the file is the same on both.

No screenshot: the window is my spaces, tabs and agents, so a picture of it would be a picture of my work rather than of the theme.
