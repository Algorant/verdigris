# verdigris for btop

TUI resource monitor. CPU, memory, disks and network at a glance.

## install

Copy `verdigris.theme` into `~/.config/btop/themes/`, then set `color_theme = "verdigris"` in `btop.conf`.

## notes

Gradients run from patina through ochre into oxblood; oxblood is a fill colour, so it is used here without its text tint.
