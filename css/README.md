# Verdigris CSS palette

This folder contains the shared Verdigris palette materials.

- `palette.json` — canonical machine-readable core palette plus additional colors.
- `palette.css` — CSS custom properties for ports and color preview tools.
- `palette-notes.md` — design notes, role decisions, and palette history.
