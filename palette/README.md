# palette

The reference for every Verdigris color. Each port under `apps/` is a bespoke, hand-kept file that takes the colors it needs from these values; nothing is generated or checked automatically.

- `verdigris.json` — names, hex and role for every color, plus the palette version
- `verdigris.css` — the same values as CSS custom properties
- `notes.md` — why each color exists, and what changed between versions
